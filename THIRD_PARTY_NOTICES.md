## Java Native Access (JNA)

Java Native Access (`net.java.dev.jna:jna`, version 5.16.0) is bundled in the desktop Client (`nqb-client-core`) to call the Windows Native Wifi API (`wlanapi.dll`) for LAN-only Wi-Fi RSSI proximity estimation and the Windows Runtime permission API (`combase.dll`) for user consent. JNA is dual-licensed under the Apache License 2.0 and LGPL 2.1+; this project uses JNA under the Apache License 2.0. Upstream notices and source information: [Java Native Access](https://github.com/java-native-access/jna).

## Anyplace KNN/WKNN

`nqb-shared/src/main/java/vn/edu/hutech/nqb/shared/fingerprint/AnyplaceKnn.java` adapts the Euclidean distance and KNN/WKNN coordinate-averaging methods from [DMSL Anyplace Algorithms.java](https://github.com/dmsl/anyplace/blob/7229551823757cc39174cc693947d9077e770bfb/clients/android/Anyplace/src/com/dmsl/airplace/algorithms/Algorithms.java).

- Upstream revision: `7229551823757cc39174cc693947d9077e770bfb`.
- Upstream file SHA-256: `85305ed267d3c9f4df33e4789377afc402305b1f6a9681b483f7b46339f19f4f`.
- Authors: C. Laoudias, G. Larkou, G. Constantinou, M. Constantinides, S. Nicolaou; supervisor Demetrios Zeinalipour-Yazti.
- Source file copyright: © 2015, Data Management Systems Lab (DMSL), University of Cyprus. Repository license also names © 2020, DMSL, Department of Computer Science, University of Cyprus.
- License: MIT. Full notices are retained in the adapted source and [the packaged license resource](nqb-shared/src/main/resources/META-INF/licenses/anyplace-MIT.txt), included in the `nqb-shared` JAR used by Server/Client.

QuizBattle changes: typed Java 21 values instead of string coordinates; double precision; input validation; explicit exact-match handling instead of weight 100; deterministic ordering with boundary ties; scaled inverse weights to avoid numerical overflow. Android, Google Maps, Realm, probability algorithms and upstream UI are not included. `FingerprintModel`, survey storage, the holdout evaluator and the exam integration are project-specific code, not represented as upstream Anyplace features or endorsements.

The synthetic golden fixture at `nqb-shared/src/test/resources/fingerprint/anyplace-golden.json` was generated by executing the unchanged upstream `Algorithms.java` at this revision, with an in-memory RadioMap and data stubs. Twelve cases cover two RSSI vectors, K=1/2/4 and KNN/WKNN. Normal, nonzero cases agree to float tolerance. Intentional changes for zero distance/ties are tested separately.

Other existing Maven libraries retain their own license files. This notice records the source adaptation introduced for fingerprinting; it is not a claim that the entire project has Anyplace's license.
